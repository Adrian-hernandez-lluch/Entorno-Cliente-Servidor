# Desarrollo Web en Entorno Cliente

Ejercicios y prácticas de JavaScript del módulo **Desarrollo Web en Entorno Cliente** (DAW), primer trimestre.

Cada carpeta es un ejercicio independiente: abre su `index.html` en el navegador para probarlo.

## Tema 2: fundamentos de JavaScript

| Ejercicio | Contenido |
|---|---|
| `Ejercicio1` | Muestra la hora y un saludo según el momento del día |
| `Ejercicio2` … `Ejercicio7` | Ejercicios del tema 2 |
| `Ejercicio Media Alumnos` | Cálculo de la media de notas de alumnos |
| `Manipulación básica de arrays con maps` | Uso de `map`, `filter` y `reduce` |
| `Constructores y métodos de String` | Biblioteca con una función constructora `Libro` |
| `Botón cambiar Tema` | Botón para cambiar entre tema claro y oscuro |
| `LocalStorage` | Guardar y leer datos con `localStorage` |
| `Cookies` | Crear y borrar cookies |
| `Práctica Gestión de Inventario de Tienda` | Práctica de inventario de una tienda |

## Tema 3: eventos, temporizadores y formularios

| Ejercicio | Contenido |
|---|---|
| `Ejercicio Contador` | Contador / reloj con `setInterval` |
| `Formulario Validación` | Validación de un formulario |
| `Formulario completo` | Formulario de inscripción |
| `Formulario Taller` | Registro de entrada de un taller |
| `Formulario Ciudades` | Gestión de ciudades con objetos y `localStorage` |
